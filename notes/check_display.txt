Docker起動スクリプトの修正

根本的には、コンテナ内で固定の、

DISPLAY=:0

を設定せず、ホスト側の値をそのまま渡すべきです。

docker runを次のようにします。

docker run \
  -e DISPLAY="$DISPLAY" \
  -v /tmp/.X11-unix:/tmp/.X11-unix:rw \
  ...

重要なのは、run.shを実行する**ホスト側シェルのDISPLAY**を使うことです。

例えばホスト側で、

echo "$DISPLAY"

が、

:1

なら、コンテナ内も自動的に、

DISPLAY=:1

になります。

現在の状態の整理

今は次の不一致です。

コンテナの接続先:
DISPLAY=:0
       ↓
必要なソケット:
/tmp/.X11-unix/X0

実際に存在するソケット:
X1
X1001

したがってQtは、

could not connect to display :0

となっています。

まずホスト側の、

echo "$DISPLAY"

と同じ値をコンテナ内へ設定すればよいです。
