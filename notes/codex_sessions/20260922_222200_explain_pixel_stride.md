User prompt:
pixel_strideとは具体的にどのようなパラメータですか？

Codex final response:
`pixel_stride`は、depth画像を何画素おきにサンプリングするかを決める間引き幅です。

現在のOAK-D depth画像は640×400で、`pixel_stride: 4`なら、縦横とも4画素おきに取り出します。処理対象は最大でおよそ160×100 = 16,000 pixelです（その後、無効depth・距離範囲外・map外を除きます）。全画素を使う場合の256,000 pixelに対して、約1/16です。

| 値 | 意味 | おおよその最大sample数 |
|---:|---|---:|
| `1` | 全pixel | 256,000 |
| `2` | 2×2ごと | 64,000 |
| `4` | 4×4ごと（現在） | 16,000 |
| `8` | 8×8ごと | 4,000 |

小さくすると細い障害物や小さい段差を拾いやすくなる一方、CPU使用量とNumPy配列処理量が増えます。大きくすると軽くなりますが、狭い岩・段差・穴の見逃しが増えます。

0.05 mセルの現在のmapでは、まず`4`がJetson向けの妥当な開始値です。Stage 2の7月bag smoke testでも、実際に有効なsampleは約5,100〜5,500点/frameで、平均約2.8 ms/frameでした。小さな障害物を評価するbagだけ`2`にして処理時間と検出の差を比較するのがよいです。
