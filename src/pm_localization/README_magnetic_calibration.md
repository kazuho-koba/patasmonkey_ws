# 磁気校正値の選択と、今後の3D校正手順

## 実機試験の既定値

`pm_config/config/hwt905_mag_calibration.yaml`は、2026-11-05のオフライン解析で求めた**緑の共通候補**を使う。初期方位を作るための暫定設定であり、完全な3D校正ではない。`calibrated: false`は維持する。

| 項目 | 試験用既定値 | 従来の暫定値 |
|---|---:|---:|
| bias_x | −848.3671934327712 | −1150.9216 |
| bias_y | −920.9509210915588 | −1056.3947 |
| scale_y | 0.8960491777027664 | 0.972729 |
| offset_deg | −7.6554087986239985 | −12.9701 |

両方ともscale_x/scale_zは1、bias_zは0、declination_degは0。z方向は未同定の固定値であり、0が正しいと確認したわけではない。新値は既存7bagのうち6件で疑似初期化の現行校正より距離中央値が改善したが、1件のp95は3.93 m→7.22 mに悪化した。実機試験の候補として採用するもので、全条件の改善を保証しない。

校正YAMLは`pm_config/config/hwt905_mag_calibration.yaml`の1つだけとする。一つ前の暫定校正値は同ファイル末尾にコメントアウトして残している。

従来値へ戻す場合は、同じYAML内の有効な`bias`、`scale`、`offset_deg`をコメントアウトし、「一つ前の暫定校正値」の3行を有効化する。新しい値へ戻す場合は逆にする。新旧を混在させず、同じキーを重複して有効にしない。`declination_deg: 0.0`と`calibrated: false`は共通なので変更不要。

通常の`pm_core.launch.py`または`pm_bag_global_localization.launch.py`で同じ共通YAMLを読む。校正を切り替える専用launch引数は設けない。変更後はcoreとGUIを再起動する。走行中の編集では既に初期化済みのEKF yawは変わらない。

共通YAMLのbias/scaleを`wit_mag_corrector`へ、同じファイルのoffset/declinationを`heading_initializer_node`へ渡す。ファイル読込・有限値・正のscaleをnode起動前に検査する。core manifestと実効parameter記録にも使用内容を残す。

GUIも既定では同じ名前のYAMLを読み、生の`/wit/mag`に補正を適用する。GUI設定のファイル名を切り替える必要はない。開発PCでGUI、Jetsonでcoreを動かす場合は、両方のworkspaceに同じYAMLの内容を反映して再起動する。異なるマシン上のファイル内容が自動同期されるわけではない。

既存の生`/wit/mag`と`/wit/imu`は変更しない。新値は`/wit/mag_corrected`と初期化時の方位計算に使う。以後wzで推定する既定local構成へ磁気yawを連続投入する変更ではない。legacy構成のWit orientation融合を磁気初期化へ置換する変更でもない。

## 今後必要な校正

磁場の一般的な補正式を`m_corrected = C (m_raw − b)`とする。`b`が3軸bias、`C`が3×3補正行列。現在のノードは`C = diag(scale)`だけを扱うため、**軸間成分を含む校正には、後述するソフトウェア拡張が別途必要**。

### 1. 計測条件を固定する

- センサ・配線・ブラケット・バッテリなどの最終搭載状態を記録する。磁気校正は搭載物や周囲の磁場の影響を受ける。
- 鉄板、鉄筋、車、工具、大きな電源配線から距離を取り、同じ場所で向きを変える測定を基本にする。スマートフォンや工具をセンサに近づけたまま回さない。
- 最初はモータ駆動をせず、給電状態を固定する。給電OFF/ON、実際の走行電流の比較は別試行にする。固定の校正値に電流で変わる外乱を一緒に吸収させない。

### 2. z成分も十分に変化する姿勢を記録する

- 水平面のyaw回転だけではz biasやxz/yz方向の歪みを十分に識別できない。磁場の測定点が3次元に広がるよう、roll/pitch/yawを組み合わせた多数の姿勢をゆっくり取り、複数回繰り返す。
- 目標は軸の正負も含む広い向きの分布であり、六面で静止するだけでなく、斜め姿勢や姿勢間の回転も記録する。六面は姿勢の網羅を確認する目安で、6点だけで一般の3D校正が十分という意味ではない。
- **重いUGVを手で大きく傾けたり反転させたりしない。** 安全に全姿勢を取れない場合、センサユニットを取り外して非磁性の治具で3D校正し、再搭載後に車体由来の誤差を別途検証する。
- 取り外した状態の校正では、車体に搭載したことで加わる磁気影響は再現できない。搭載状態で数度しか傾けられないなら、その範囲の検証はできても、車体込みの完全な3D校正ができたとは扱わない。

### 3. 保存する情報

| 情報 | 用途 |
|---|---|
| 生の`/wit/mag`、header/frame | 3軸のbias/行列を再推定する主データ |
| `/wit/imu` | roll/pitch、角速度、加速度を使った姿勢・動作の照合 |
| `/wit/mag_corrected` | 現行補正との比較。生データの代わりにはしない |
| `/tf_static`、必要な`/tf` | センサ取付姿勢と車体座標の確認 |
| 校正YAML・実効parameter・初期化status | どの値を使ったか、初期化の成否とseedを追跡 |
| `/motor_state`、給電・電流・動作段階のメモ | 電気的条件が変わる影響を分離。取得できる電流の種類も明記 |
| `/fix`、`/navpvt`、wheel odometry | 屋外前進での独立な方位照合。静止1アンテナGNSSは機体方位の基準にはならない |

先に録画を始め、その後初期化する順序で、初期化に採用する前後の磁気も保存したい。現在の実走行bagのようにREADY後から記録すると、初期化に採用したサンプルを再検査できない。現在のcoreが既に初期化を終えている場合、単に録画開始するだけでは過去の初期化入力は記録できない。

最低時間を満たすだけでなく、測定点が3次元に広く分布していること、飽和・欠測がないことを確認する。最初は数分程度の試行を目安にできるが、時間やデータ件数だけを校正の成功条件にはしない。

### 4. オフラインで3D楕円体を推定する

均一な磁場内で向きを十分に変えると、理想的な3軸測定点は球面上に分布する。biasと歪みがあると中心のずれた楕円体になるため、外れ値を除外しつつ楕円体を当てはめ、中心から3軸bias、形から3×3の補正行列を求める。補正後の点群を球面へ近づける考え方は[NXP AN4246](https://www.nxp.com/docs/en/application-note/AN4246.pdf)に基づく。

行列が正定値であること、推定の条件が悪くないこと、方位分布が十分であることを確認する。absoluteな磁場強度を別に与えない場合、共通倍率には規約・正規化が必要となる。Witのraw register値をTeslaと誤認して地磁気の絶対値へ比較しない。

球面にそろうことだけでは、座標軸の回転や車体との取付方向が正しいとは保証できない。楕円体の点群だけでは回転に自由度が残るため、補正行列の規約と取付TFを分け、roll/pitchによる方位変化、既知方位、必要ならgyroを併用した軸整合検証も行う。[NXP AN4246](https://www.nxp.com/docs/en/application-note/AN4246.pdf)

### 5. 軸間校正を使うためのソフトウェア対応

現在の`hwt905_rs485_driver/wit_mag_corrector`は3軸biasと軸別scaleのみ。今後行列を使う場合は、従来のscale指定を維持しつつ、3×3行列を選択できるパラメータを追加する必要がある。

- 磁気補正ノードは`C(m − b)`とし、共分散も`C Σ Cᵀ`へ変換する。
- 生磁気から独自に方位を求めるGUIとオフライン解析も、同じ行列を使用する。GUIに別の補正を重ねない。
- launchの校正検査、設定のbag保存、実効parameterの記録、回帰テストも行列へ対応させる。
- 方位offset・偏角はベクトルの校正後に扱い、取付TFの回転やENUへの変換と二重適用しない。

この拡張は今回の変更には含めない。必要な3Dデータを取得して、行列の同定・独立評価ができてから実装する。

### 6. 未使用データで確認する

- 校正に使っていない姿勢・別試行で、磁場ノルムのばらつきと方位誤差を評価する。
- 同じ場所・同じyawでroll/pitchを変えたときの方位変化を確認する。小さなばらつきだけで真北に合うと判断しない。
- 同じyawを別の場所で測り、外部磁場の影響を分離する。
- モータ給電状態・実走行電流を変え、固定行列で補償できる成分と動的外乱を分ける。
- 最後に屋外の十分な距離の直進、斜面、往復走行でGNSS進行方向・オドメトリを比較する。悪化する姿勢・場所・電気条件が残るなら、校正値を一律採用せず磁気による初期化を保留する条件などを検討する。

軸別biasと行列によるhard/soft iron補償、磁気外乱時の方位利用については[ST DT0058](https://www.st.com/content/ccc/resource/technical/document/design_tip/group0/56/9a/e4/04/4b/6c/44/ef/DM00269987/files/DM00269987.pdf/jcr%3Acontent/translations/en.DM00269987.pdf)も参照。上の試行順序とUGVでの実施方法は、このリポジトリの構成・車体条件に合わせた提案である。
